# My Planning Task

Aplicación web para organizar tareas mediante un tablero visual.

## Funcionalidades

- Crear tareas.
- Validar campos del formulario.
- Visualizar tareas en tarjetas.
- Clasificar tareas por estado.
- Eliminar tareas.

## Tecnologías

- HTML
- CSS
- JavaScript
- Bootstrap 5

## Estados

- Pendiente
- En Progreso
- Revisión
- Hecho
